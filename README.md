После установки в Revit появляется вкладка **MazzaBIM**. Обновления приходят сами: значок MazzaBIM в трее
находит новую версию, проверяет её подпись и ставит, когда Revit закрыт. Любую функцию можно выключить в менеджере
обновлений, если она не нужна.

## Как установить

1. Скачать [MazzaBIM-Setup.exe](https://github.com/lekkrit/MazzaBIM/releases/latest/download/MazzaBIM-Setup.exe).
2. Запустить и отметить свои версии Revit. Права администратора не нужны.
3. Открыть Revit.

Удалить — «Параметры → Приложения → MazzaBIM».

## Обновления

Менеджер обновлений запускается вместе с Windows и проверяет новые версии каждые 4 часа. Скачанный установщик
сверяется с подписанным описанием выпуска — подменённый файл не установится. Если новая версия не понравилась,
в менеджере есть «Вернуть версию».

## Требования

Windows 10 или 11, Autodesk Revit 2024, 2025 или 2026. Ничего дополнительно ставить не нужно.
